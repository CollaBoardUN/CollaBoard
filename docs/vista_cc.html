CollaBoard — Vista de Componentes y Conectores (C&C)

Módulos: Pixels, Auth, Colaboración y Pizarra · Flujo vertical simplificado en blanco y negro

CATÁLOGO DE CONEXIONES Y PUERTOS EN DOCKER
Origen Destino Protocolo Puerto Docker (Host ➔ Container) Endpoint / Ruta Función de la Conexión
pixel_frontend pixel_backend HTTP REST 8080:8000 GET /api/pixels/board, /stats Carga inicial del lienzo 200×200 y métricas de colaboradores.
pixel_frontend pixel_backend WebSocket 8080:8000 WS /ws/pixels Envío de PLACE_PIXEL y difusión en vivo de trazos en píxeles.
auth_frontend auth_backend HTTP REST 8001:8000 POST /auth/login, /register Autenticación de credenciales y retorno de Token JWT.
pizarra_frontend colaboracion_module HTTP REST 8002:8000 GET/POST /boards, /invites Gestión de tableros, invitaciones y roles de miembros (RBAC).
pizarra_frontend pizarra_backend HTTP REST 8000:8000 GET/POST /elements Lectura y persistencia de trazos y figuras geométricas.
pizarra_frontend pizarra_backend WebSocket 8000:8000 WS /ws/canvas Sincronización bidireccional en vivo de trazos y cursores de usuarios.
pixel_backend nosql_db TCP NoSQL 27017:27017 mongodb://pixels-nosql-db:27017 Driver Motor (Mongo Wire): upserts atómicos de píxeles sin bloqueo.
auth_backend sql_db TCP SQL 5432:5432 postgresql://pizarra-db:5432/pizarra Persistencia de usuarios, credenciales y hashes de contraseñas.
colaboracion_module sql_db TCP SQL 5432:5432 postgresql://pizarra-db:5432/pizarra Persistencia de tableros, membresías y tokens de invitación urlsafe.
pizarra_backend sql_db TCP SQL 5432:5432 postgresql://pizarra-db:5432/pizarra Persistencia relacional de elementos del lienzo (clave foránea con CASCADE).
