\subsection{Variables de entorno}

Los valores por defecto de Docker Compose sirven para la demostración. Las variables principales son:

\begin{table}[H]
\centering
\small
\filas
\begin{tabularx}{\linewidth}{@{}P{4.4cm} L@{}}
  \encabezado \hd{Variable} & \hd{Uso} \\
  \code{JWT\_SECRET} & Clave HS256 compartida por Auth y las APIs (mínimo 32 bytes) \\
  \code{GATEWAY\_INTERNAL\_URL} & URL interna del gateway que usa el servidor de la web SSR \\
  \code{SESSION\_COOKIE\_SECURE} & \code{true} solo detrás de HTTPS (la cookie de sesión exige \textit{Secure}) \\
  \code{PUBLIC\_WS\_URL} & Base \code{ws(s)://} de los WebSocket del navegador; vacío = mismo origen \\
  \code{*\_DATABASE\_URL}, \code{MONGODB\_URL} & Conexión de cada servicio con su propio almacén \\
  \bottomrule
\end{tabularx}
\caption{Variables de entorno más relevantes. Cada módulo documenta las suyas en \code{.env.example}.}
\end{table}

\subsection{Construir, iniciar y verificar}

\begin{lstlisting}[language=bash]
# Construye las imágenes e inicia todos los contenedores en segundo plano
docker compose up --build -d

# Estado: todos deben aparecer "healthy" o "running"
docker compose ps

# Verificación rápida por el gateway
curl -s http://localhost:<puerto-gateway>/healthz
\end{lstlisting}

Abrir \url{http://localhost:<puerto-gateway>} en el navegador, crear una cuenta y un tablero.

\begin{pendiente}{Sebastian (instrucciones finales)}
Reemplazar \code{<puerto-gateway>} y \code{<revision-probada>} con los valores del despliegue final,
agregar el paso de migraciones si queda manual y la instalación del cliente local (ruta del
instalador o \code{npm run make} en \code{desktop-client/} y cómo configurar la URL del gateway).
\end{pendiente}

\subsubsection*{Estado actual verificable: web SSR con el stack del prototipo 1}

Mientras se integran el gateway definitivo, Chat y Notificaciones, la web SSR se puede ejecutar
de punta a punta con un \emph{override} de Compose que agrega la web, mocks de Chat y
NotificationAPI con el contrato acordado y un gateway de desarrollo:

\begin{lstlisting}[language=bash]
docker compose -f docker-compose.yml -f web-ssr/compose.dev.yml up --build -d
# -> http://localhost:8088

# Pruebas de la web
cd web-ssr && npm ci
npm run lint && npm run typecheck && npm test
npm run build && npm run test:ssr

# Punta a punta (desde la raíz, con el stack arriba)
pip install -r e2e/requirements.txt && python -m playwright install chromium
WEB_SSR_URL=http://localhost:8088 pytest e2e/test_web_ssr.py -v
\end{lstlisting}

\end{lstlisting}
